## Practice Rules

- Start with recursion and identify repeated subproblems.
- Add memoization to avoid repeated calculations.
- Convert recursive solutions into tabulation.
- Learn how to define DP states and transitions.
- Trace small examples manually.
- Optimize space only after understanding the full solution.
- Analyze time and space complexity.
