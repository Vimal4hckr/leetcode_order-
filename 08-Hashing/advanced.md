## Practice Rules

- Learn prefix sums before advanced range-sum problems.
- Understand rolling hash concepts before duplicate-substring problems.
- Combine hash maps with linked lists when implementing cache structures.
- Aim for the required time complexity, not only a correct output.
- Test collisions, duplicate values, and boundary cases.
- Analyze time and space complexity.
