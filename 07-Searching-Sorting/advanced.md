## Practice Rules

- Learn binary search on the answer after mastering standard binary search.
- Understand quickselect and partitioning.
- Study merge sort before counting inversions or reverse pairs.
- Use heaps when maintaining ordered data dynamically.
- Test extreme values and duplicate elements.
- Analyze time and space complexity.
