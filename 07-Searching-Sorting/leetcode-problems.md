## Practice Rules

- Solve the questions in order.
- Implement linear search before binary search.
- Understand why binary search requires sorted data.
- Learn bubble sort, selection sort, and insertion sort before studying optimized sorting algorithms.
- Test duplicates, empty arrays, and boundary indices.
- Analyze time and space complexity for every solution.
