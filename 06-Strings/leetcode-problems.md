## Practice Rules

- Solve the problems in order.
- Practice indexing and character traversal.
- Understand ASCII values and character frequency.
- Try straightforward solutions before optimizing.
- Test empty strings, repeated characters, and case differences.
- Learn time and space complexity after each solution.
