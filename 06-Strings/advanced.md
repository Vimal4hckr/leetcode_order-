## Practice Rules

- Understand brute-force pattern matching before learning KMP.
- Master sliding windows before minimum-window problems.
- Learn two-dimensional DP before advanced string DP.
- Trace indexes carefully and test repeated characters.
- Explain why each optimization works.
- Analyze time and space complexity.
