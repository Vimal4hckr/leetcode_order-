## Learning Objectives

After completing these problems, you should be able to:

- Apply Dijkstra's algorithm and other shortest-path techniques.
- Use Disjoint Set Union (DSU) to manage connectivity.
- Understand minimum spanning tree algorithms such as Prim's and Kruskal's.
- Identify bridges and analyze graph connectivity.
- Solve graph transformation and state-space search problems.
- Choose suitable graph algorithms based on constraints and edge weights.
