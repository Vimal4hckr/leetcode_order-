## Practice Rules

- Understand LIFO (Last In, First Out) and FIFO (First In, First Out).
- Implement basic stack and queue operations first.
- Trace every push, pop, enqueue, and dequeue operation.
- Learn monotonic stacks only after understanding ordinary stacks.
- Test empty structures and boundary cases.
- Analyze time and space complexity.
