## Learning Objectives

After completing these problems, you should be able to:

- Use monotonic stacks to solve histogram, visibility, and range problems.
- Design data structures that combine stacks with auxiliary structures.
- Apply monotonic deques to sliding-window and dynamic programming problems.
- Parse arithmetic and Boolean expressions using stacks.
- Recognize when a stack or deque can improve an algorithm's time complexity.
