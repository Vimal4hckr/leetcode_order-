## Practice Rules

- Begin with a brute-force solution.
- Identify repeated calculations and eliminate them.
- Learn prefix sums before advanced subarray counting.
- Master fixed-size windows before variable-size windows.
- Understand when a sliding window is valid for a problem.
- Test edge cases and analyze time and space complexity.
