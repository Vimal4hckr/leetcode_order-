## Practice Rules

- Define the recursive state and base case clearly.
- Draw the recursion tree for small examples.
- Use a choose, explore, and backtrack pattern.
- Learn pruning to avoid unnecessary branches.
- Handle duplicate combinations carefully.
- Analyze time and space complexity.
