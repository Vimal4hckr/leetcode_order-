## Practice Rules

- Solve the questions in order.
- First understand array indexing and traversal.
- Try a brute-force solution before optimizing.
- Test empty arrays, single-element arrays, and duplicate values where applicable.
- Learn time and space complexity after solving each problem.
- Write your own code before viewing the editorial.
