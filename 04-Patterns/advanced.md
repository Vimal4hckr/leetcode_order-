## Practice Rules

- Master matrix boundaries and traversal directions.
- Learn in-place modification techniques.
- Use binary search or heaps when appropriate for matrix search problems.
- Practice backtracking before attempting Sudoku Solver.
- Learn dynamic programming before advanced path problems.
- Analyze time and space complexity.
