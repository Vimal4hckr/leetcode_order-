## Learning Objectives

After completing these problems, you should be able to:

- Implement recursive and iterative tree traversals.
- Use queues for level-order traversal.
- Calculate tree depth, diameter, and balance.
- Search, insert, delete, and validate nodes in a BST.
- Construct trees from traversal sequences.
- Solve path-based problems using recursion and backtracking.
